Method

How it works

  1. Start with BOLT11. Mainnet invoices usually begin with lnbc.
  2. Encode it. Append the exact invoice to https://cash.app/launch/lightning/.
  3. Open on tap. On phones with Cash App, the universal link can load the payment screen.
  4. Keep fallback. If the link fails, copy the invoice and paste it into Cash App.
  5. Optional sample. The button resolves austin@vlt.ge and requests amount=1000 msats.

Recipe

Core code

const cashAppLightningUrl =
  `https://cash.app/launch/lightning/${encodeURIComponent(bolt11)}`;

The demo runs in the browser. It does not store invoices or attempt payment.
